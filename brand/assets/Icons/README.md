Favicon and app icons, built from the simplified mark (heavier rim) so they hold up at small sizes.

- `favicon.svg`: `sakura-red` mark on transparent, `blush` in dark mode. Link it first, with `favicon-32.png` as the fallback.
- `favicon-16.png`, `favicon-32.png`, `favicon-48.png`: `sakura-red` on transparent, for browsers without SVG favicons (the brand kit also holds `favicon.ico`, which packs these three).
- `apple-touch-icon.png`: 180px, mark in `sakura-red` on a full `white` square (iOS rounds the corners itself).
- `icon-192.png` and `icon-512.png`: `sakura-red` mark on a `white` square, with the mark inside the central 60% so the icon survives circular masks. `icon-512.png` uses the full-detail mark.
