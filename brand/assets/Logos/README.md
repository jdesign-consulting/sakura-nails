Logo files, traced from the owner's final Canva artwork ("sakura" in AR Mincho size 233, NAILS in Agrandir Wide size 65). All text is already outlines, so no font is needed to display them. Names are unchanged from the first version of the kit, so they can be swapped in place.

- `logo-lockup.svg`: mark, "sakura" and NAILS all in `sakura-red`, on transparent. The default; use on `white`, `blush-light` and `blush`.
- `logo-lockup-reversed.svg`: all `white` artwork on a `sakura-red` background.
- `logo-lockup-mono-dark.svg`: single ink, `ink` (#2B1B1A), for one-colour printing and stamps.
- `logo-wordmark.svg` and `logo-wordmark-reversed.svg`: "sakura" and NAILS without the mark.
- `logo-mark.svg` and `logo-mark-reversed.svg`: the five-petal mark alone, in `sakura-red` or `white`, on transparent.
- `logo-mark-simplified.svg`: the mark with a heavier rim around each nail, for use below 64px.
- `logo-lockup-2000.png`, `logo-lockup-reversed-2000.png` and `logo-mark-1024.png`: PNG exports (transparent, except the reversed lockup on red) for tools that cannot take SVG.
