Favicon and app icons, built from the simplified mark.

- `favicon.svg`: `sakura-red` nail beds on a pale nail shape (30%), `blush` in dark mode, on transparent. Link it first, with `favicon-32.png` as the fallback.
- `favicon-32.png`: `sakura-red` on transparent, for browsers without SVG favicons.
- `apple-touch-icon.png`: 180px, mark in `sakura-red` on a full `cream` square (iOS rounds the corners itself).
- `icon-192.png` and `icon-512.png`: `sakura-red` mark on a `cream` square, with the mark inside the central 60% so the icon survives circular masks.
